# 贡献指南（规划）

## 开发原则

- 保持 MCP 工具协议稳定，供应商细节封装在 Provider；
- 不提交 API Key、真实图片、真实响应和个人路径；
- 变更先补测试和文档，再修改实现；
- 不擅自扩大下载目录、网络访问和文件覆盖权限；
- RPM、错误码和安全边界发生变化时同步更新文档。

## 提交前检查

```text
类型检查
单元测试
Agnes mock 集成测试
stdio 冒烟测试
安全扫描
依赖许可证检查
文档检查
```

## Issue 建议内容

- 使用的工具名称；
- 脱敏后的输入参数；
- 期望行为和实际行为；
- 运行环境与 Node.js 版本；
- 是否使用 mock；
- 脱敏日志和复现步骤。

请勿上传 API Key、Authorization 请求头、私有图片 URL 或未经授权的生成内容。

## Pull Request 要求

- 说明变更动机和影响范围；
- 列出测试命令与结果；
- 说明是否改变工具 schema；
- 若改变 API 映射，附 Agnes 官方文档依据；
- 若改变安全策略，补充威胁分析和回归测试。
