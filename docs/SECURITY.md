# 安全设计与开源边界

> 📚 **本文档隶属 [文档总纲](README.md)** — 关键事实以总纲 §2 SSOT 为准；修改本文档须遵守总纲 §3 同步铁律。
>
> 当前版本已实现安全底座；发布前仍须通过本文 §6 的安全与依赖门禁。

## 1. 凭据安全

- 只从进程环境读取 `AGNES_API_KEY`；
- `AGNES_MODEL` 只作为默认模型，不存放密钥；
- API Key 不允许出现在工具参数、返回值、日志、异常、测试夹具和 Git 历史；
- stdout 仅用于 MCP 协议，诊断日志写 stderr；
- README 只提供占位配置，不提供真实凭据；
- CI 使用假 Key 和 Agnes mock，不调用真实 API。

## 2. 本地路径沙箱

`download_image` 和 `validate_image` 涉及文件系统时，第一版默认只允许解析后位于 `process.cwd()` 下面的路径；`validate_image` 仅接受本地路径：

- 拒绝绝对路径；
- 拒绝 `..` 路径穿越和 NUL 字符；
- 拒绝符号链接；
- 下载默认拒绝覆盖已存在目标；
- 限制单文件字节数；
- 不递归创建或删除用户目录；
- 不提供任意目录清理能力。

如果未来支持安全根目录，必须通过显式的受控运行参数注入，不能由每个工具调用随意扩大范围。

## 3. 网络与 SSRF

`download_image` 仅接受 HTTPS 图片 URL：

- 拒绝 `file://`、`data:`（下载工具）、`ftp://` 等非 HTTPS scheme；
- 解析 DNS 后拒绝环回、内网、链路本地、云元数据和保留地址；
- 限制重定向次数；
- 每次重定向重新执行 URL 和地址校验；
- 限制响应大小和请求超时；
- 校验响应 Content-Type 与图片魔数，不信任文件扩展名；
- 不发送调用方 Cookie 或私有请求头。

## 4. Agnes 请求安全

Provider 只构造官方允许的字段：

- `response_format` 只能放到 `extra_body`；
- 图生图图片只能放到 `extra_body.image`；
- 不透传未声明的顶层字段；
- 错误响应统一映射，避免回显 Authorization；
- 请求超时和响应体大小有上限；
- 只对网络错误、超时和 429 等可恢复错误重试。

## 5. 开源授权边界

MIT 仅覆盖本项目代码，不代表：

- Agnes API 的授权；
- Agnes 模型输出的商业或内容授权；
- 用户输入图片的版权；
- 生成图片的第三方权利；
- Agnes 官方文档的再发布授权。

仓库不得复制 Agnes 私有 SDK、受限协议实现或文档受限内容。README 应链接 Agnes 官方文档，并要求使用者自行遵守 Agnes 服务条款、内容政策和适用法律。

## 6. 发布前检查

- 扫描密钥、Token、Cookie 和个人路径；
- 扫描真实图片、真实 API 响应和日志；
- 检查 `.gitignore`、npm pack 内容和 lockfile；
- 执行依赖许可证扫描和依赖漏洞扫描；
- 确认所有第三方依赖许可证兼容 MIT；
- 确认发布包不包含测试夹具、真实素材和密钥；
- 更新 CHANGELOG 和安全报告入口；
- 记录 Agnes 官方文档链接、版本和已知 RPM 限制。
